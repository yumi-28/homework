# 카운터 앱

## 실행 결과

### 더하기 버튼을 누르면 1씩 증가
### 빼기 버튼을 누르면 1씩 감소
### 숫자가 0보다 작아지지 않게 제한하고 숫자가 홀수일 경우 빨간색으로 짝수일 경우 파란색으로 표시

# TodolistApp

## 실행 결과

### 입력 창에 할 일 입력 후 입력 버튼을 누르면 todos 리스트에 삽입 후 출력
### 완료/삭제 버튼 중 완료 버튼을 누르면 텍스트에 취소선 적용 및 완료 필터 적용
### 삭제 버튼을 누르면 todos리스트에서 삭제
### 맨 밑에 전체/미완료/완료 버튼 중 전체 버튼을 누르면 todos 리스트의 전체 요소 출력
### 미완료 버튼을 누르면 todos 리스트의 완료 버튼이 눌리지 않은 요소만 출력
### 완료 버튼을 누르면 todos 리스트의 완료 버튼이 눌린 요소만 출력

# QuizApp

## 실행 결과

### questions 리스트의 문제와 option이 출력
### 옵션 버튼을 누르면 다음 문제로 바뀌고 문제 출력 후 5초 동안 버튼이 눌리지 않아도 다음 문제로 바뀜
### questions 리스트의 마지막 문제까지 출력 후 점수 출력과 다시풀기 버튼이 생성
### 다시 풀기 버튼을 누른다면 점수와 문제 인덱스 모두 초기화되어 다시 문제가 출력됨
